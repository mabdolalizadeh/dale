# 🇪🇸 Dale

> Learn Spanish the smart way.

**Dale** is a modern mobile application designed to make learning Spanish enjoyable, practical, and accessible for everyone. Whether you're taking your first steps in Spanish or strengthening your existing skills, Dale provides an engaging learning experience through interactive lessons and real-world practice.

## 🌍 Languages

- 🇬🇧 English
- 🇪🇸 Español

# 🇬🇧 English

## About

Dale is a Spanish learning application focused on helping learners build real communication skills through interactive exercises, vocabulary practice, grammar lessons, listening activities, and speaking practice.

Our mission is to make Spanish learning simple, engaging, and effective for learners of all levels.

## Features

- 📚 Structured learning path
- 📝 Vocabulary building
- 🎧 Listening exercises
- 🗣️ Speaking practice
- ✍️ Grammar lessons
- 🎯 Interactive quizzes
- 📈 Progress tracking
- 📱 Clean and intuitive user interface

## Who is it for?

Dale is designed for:

- Complete beginners
- Intermediate learners
- Students
- Travelers
- Professionals
- Anyone interested in learning Spanish

## Technology

The application is built with modern technologies to provide a fast, reliable, and scalable experience.

## Vision

We believe language learning should be:

- Practical
- Enjoyable
- Consistent
- Accessible for everyone

Dale helps learners gain confidence by practicing Spanish every day.

# 🇪🇸 Español

## Acerca de

Dale es una aplicación para aprender español diseñada para ayudar a los estudiantes a desarrollar habilidades reales de comunicación mediante ejercicios interactivos, práctica de vocabulario, gramática, comprensión auditiva y expresión oral.

Nuestra misión es hacer que aprender español sea sencillo, entretenido y efectivo para estudiantes de todos los niveles.

## Características

- 📚 Ruta de aprendizaje estructurada
- 📝 Desarrollo de vocabulario
- 🎧 Ejercicios de comprensión auditiva
- 🗣️ Práctica de conversación
- ✍️ Lecciones de gramática
- 🎯 Cuestionarios interactivos
- 📈 Seguimiento del progreso
- 📱 Interfaz moderna e intuitiva

## ¿Para quién es?

Dale está pensado para:

- Principiantes
- Estudiantes de nivel intermedio
- Universitarios
- Viajeros
- Profesionales
- Cualquier persona interesada en aprender español

## Tecnología

La aplicación está desarrollada con tecnologías modernas para ofrecer una experiencia rápida, segura y escalable.

## Nuestra visión

Creemos que aprender un idioma debe ser:

- Práctico
- Divertido
- Constante
- Accesible para todos

Dale ayuda a los estudiantes a ganar confianza practicando español todos los días.
